# İz Ara

Turkish-language static music and sheet-score search app. No build step is required.

## Run locally

Serve this folder over HTTP, for example with `python -m http.server 8765`, then open `http://localhost:8765`.

## GitHub Pages

The `pages.yml` workflow deploys this static site to GitHub Pages on pushes to `main`.

The site is mobile-friendly and installable as a PWA. It searches public archives and does not upload your TXT list.
